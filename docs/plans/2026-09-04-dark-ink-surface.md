> 状态：**计划，未获批准不动代码**。改动面：暗色令牌表 + 新增一对填充令牌（浅色取同值，零视觉变化）+ 六条 CSS 规则的令牌引用调整；**零 DOM/组件结构改动**。

## 一、诊断：绿油油的两个根因

**根因① 绿当了环境**：暗色画布五个大面（bg/surface/surface-2/surface-3/border）全带绿味（g 通道 +4~+11），绿成了 100% 的空气；暗模式下大面积低亮度表面放大色彩感知（同时对比效应），暖纸白文字压在绿面上更显得绿。

**根因② 绿当了高亮填充（v1 漏掉的）**：浅色模式的按钮是**深墨绿块 `#00432B` + 纸字**——含蓄如墨，这是品牌身份；暗色却把同一身份做成了 `#7CC791` 荧光叶绿填充。数据：**亮绿填充与画布的亮度跳变高达 8.69 倍**——这就是「油」的物理来源。且顶栏同时存在两块荧光绿（登录按钮 + 品牌徽章），绿又遍布选中/连线/印章等十余处，累积成灾。

**设计判据**：高级的暗色里，品牌色必须分级——**亮叶绿只能当「笔」**（文字/细线/小记号：面积小、对比高），**大面积填充必须用「深墨块」**（靠与画布的对比显形，不靠亮度发光）。浅色模式本来就符合这条；暗色要向它对齐，而不是反向发明一套荧光语汇。

## 二、方案

### 2.1 画布去绿归炭（同 v1，未变）

| 令牌 | 夜林现值 | 墨面新值 |
|---|---|---|
| `--bg` | `#0D110D` | `#0F1211` |
| `--surface` | `#151B16` | `#171B19` |
| `--surface-2` | `#1D281B` | `#202523` |
| `--surface-3` | `#24322A` | `#292F2C` |
| `--border` | `#2A382E` | `#2C332F` |
| `--border-strong` | `#3D5042` | `#3D453F` |
| `--text` | `#E8E3D6` | `#E6E4DC` |

`--text-secondary/--text-muted` 的墨绿灰**不变**（文字属墨水角色，与浅色同构）；语义色/洗底/阴影/颗粒不变。

### 2.2 墨水分级：新增「填充层」令牌

| 令牌 | 浅色（不变） | 暗色新值 | 用途 |
|---|---|---|---|
| `--accent-fill` | `#00432B`（=现 accent） | `#35714E` 深墨绿 | 大面积填充：主按钮、品牌徽章、进度条、完成节点 |
| `--accent-fill-hover` | `#00602F` | `#3F8159` | 填充 hover |
| `--accent-contrast` | `#FBF9F3`（不变） | `#F0EDE2` 纸白（现 `#102016` 墨字——那是配荧光绿的字） | 填充上的文字 |
| `--accent` | 不变 | **不变 `#7CC791`** | 「笔」：链接/选中文字/细线/连线/印章描边 |

数值（脚本复核）：深墨绿上纸字 **4.94**（AA）✓；hover 上 **3.99**（UI 层达标）✓；填充与画布亮度差 **3.00**（对比显形，非发光）✓；亮叶绿作笔 **8.64**★ 不变。

### 2.3 六条 CSS 规则换用填充层（零 DOM 改动）

`.btn.primary`、`.brand-mark`、`.progress-bar`（含流光渐变改 `--accent-fill → --brass`）、`.stage-step.done .stage-dot`、`.mindmap-badge`、`.thumb-origin.evidence`。其余 accent 引用（链接、选中行、时间戳描边、连线、问答渐变边……）**全部保持亮叶绿**——它们是笔。

同步：`src/main/index.ts` 暗色 `backgroundColor` → `#0F1211`。
