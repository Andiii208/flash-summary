## 一、问题定性：为什么现在的界面「毫无设计性」

2024-2026 年「AI 生成界面」已聚成三种默认脸，本方案逐条对照自查（这是评审时最该苛刻的一点）：

| 模板特征 | 本应用现状 | 命中 |
|---|---|---|
| indigo/紫点缀 + 灰蓝中性色 | `--accent #3b5bdb`、`--bg #f2f4f9` 灰蓝 | ✅ |
| 全系统字体栈、无排版角色分工 | Segoe UI/YaHei 一套走天下，层级只靠字号加粗 | ✅ |
| 万物圆角卡片 + 柔和双阴影 | 11px 圆角 + 双层阴影的卡片盖住包括笔记正文在内的一切 | ✅ |
| 布局气质 = SaaS 后台 | 顶栏+分段页签+三栏，与任何管理后台无差别 | ✅ |
| 与产品主题零关联 | 「大学课程学习笔记」工具，视觉与主题无一字关联 | ✅ |

图像模型对基线的目检结论（多张独立批评一致）：**功能齐全的原型，不是产品**——排版层次弱、色彩无个性、卡片无精致度、行长无度量（780px）、交互反馈存在但无签名感。对笔记质变新增组件（时间线卡/概念卡/公式块/图集）的专项批评：**「尚可但粗糙」「未融入细节质感、略显突兀」**——功能就位、视觉欠账，正是本轮要还的。

**根因**：现在的 design system 是「通用令牌集」（哪个产品都能用=哪个都不像），而不是「这个产品的视觉身份」。解法不是打磨现有令牌，而是**换一套从产品世界长出来的设计语言**，并让笔记质变新增的 8 个组件类（NoteBlocks 全家/MindMap/MdLite/PrintHandout）直接生于这套语言。

## 二、设计语言：«文楷纸张 · 礼堂墨绿»

一句话：**把界面从「SaaS 后台」变成「东南大学图书馆里的一叠讲义」**——暖宣纸底、墨绿墨水、铜金点睛、文楷标题、宋体正文、等宽时间、发丝线分层、纸纹颗粒。

五根支柱（每根都有出处，不是凭空审美）：

1. **色彩 · 校色有据**：东南大学校色为深绿（大礼堂绿穹顶），校训「止于至善」，四牌楼梧桐。主墨 = 礼堂墨绿 `#00432B`，辅点 = 铜金 `#6E5426`（铜绿穹顶经年的金属色），纸面 = 暖白宣纸。绿+铜是「图书馆装帧」的配色，不是银行绿——守则见 §3.3。
2. **排版 · Craft 的 CJK 策略**（craft.do 生产 CSS 实证）：中文文档应用必须给中文一个「文档级」字体。四角色：文楷显示 / 宋体正文 / 黑体 chrome / 等宽时间。
3. **表面 · 纸张层次**：层级靠**纸台阶**（bg 桌面 → surface 纸页 → 1px 发丝线）表达，圆角阴影只留给真正悬浮的东西（toast/dialog/图片放大 Dialog）。浅色近乎无边框（Notion/Craft 实证），暗色用「色阶表面+发丝线」不用模糊阴影（Linear 实证）。
4. **动效 · 三处签名，其余静默**：只动「管线阶段翻转、进度流光、toast 入场」三处（M3 时长/缓动令牌）；高频交互一律瞬时（Rauno 原则）。
5. **图形 · 产品自有文物**：大礼堂柱廊剪影（手绘 SVG）用于空态/欢迎卡；印章式状态与中文数字；「止于至善」作设置页脚铭。**这些图形只属于这个产品**。

**对照自查（为什么不落入 AI 默认脸）**：本方向用了「暖纸+衬线」元素，与默认脸之一（暖奶油+高对比衬线+陶土点缀）表面相近，五处刻意避开：① 显示字是**楷体**（中文书写传统）非 Latin 编辑衬线；② 点缀是**墨绿+铜金**，零紫零蓝零陶土；③ 等宽时间戳是一等公民角色；④ 层次用纸台阶而非阴影卡片；⑤ 签名元素全部来自产品自身内容（证据帧/六阶段/大礼堂）。

### 3.2 字体系统（四角色，npm 切片包，全部 OFL-1.1 已在 npm 验证存在）

| 角色 | 字体 | 包 | 栈 |
|---|---|---|---|
| 显示 | 霞鹜文楷 | `@fontsource/lxgw-wenkai` 5.3.0 | `'LXGW WenKai', serif` |
| 笔记正文 | 思源宋体 | `@fontsource/noto-serif-sc` 5.3.0 | `'Noto Serif SC', serif` |
| UI chrome | 思源黑体 | `@fontsource/noto-sans-sc` 5.3.0 | `'Noto Sans SC', 'Microsoft YaHei UI', system-ui` |
| 时间/数字 | JetBrains Mono | `@fontsource/jetbrains-mono` 5.3.0 | `'JetBrains Mono', Consolas, monospace` |

- **切片即离线**：fontsource 包是 unicode-range 切片 woff2，Vite 打进 asar，运行时零网络（CSP/离线红线不破）。
- 体积约 +35-50MB（安装包现 258MB 含 80MB ffmpeg，可承受；精简备选见 §8 决策点）。
- clreq 守则：**中文标题零字距**；正文行高 1.75-1.85；笔记正文行长 34-38 字 → `max-width: 660px`；数字一律 `tabular-nums`。
- 字号阶梯（基线批评「偏小」）：md 13.5→14px、lg 15.5→16px、xl 18→20px；笔记正文 16px/1.85。
- **print.css 不动**：已核实零变量引用、自包含，打印讲义保持纸白高对比，恰好符合本语言。

### 3.3 图形守则（防「银行感」）

1. 绿只做**墨水**（文字/线/小面积选中），不做大色块填充；
2. 载体是**纸**不是白板：暖白+颗粒+发丝线，不用纯白+柔和阴影；
3. 圆角三档：纸张内容 4px / 控件 6px / 悬浮层 10px（现 7/11/15 全档收紧）；
4. 阴影只给 toast/dialog（模糊度减半），其余层次用表面色阶+发丝线；
5. 颗粒纹理：feTurbulence 噪声 SVG 平铺 body，3-4% 不透明度（浅色 multiply/暗色 screen），css-tricks 验证配方——「未涂布纸」物理感，消除纯色 banding。

### 3.4 动效令牌（M3 + Rauno）

点击反馈 ≤100ms；面板/toast 250ms；签名动效 450ms。标准缓动 `cubic-bezier(0.2,0,0,1)`，强调减速 `cubic-bezier(0.05,0.7,0.1,1)`（阶段落定）。高频操作零动画；`prefers-reduced-motion` 全局豁免保留。进度流光换绿→铜金渐变位移。

### 3.5 图标

`lucide-preact` 1.40.0（ISC；peer preact ^10.27.2 兼容现用 10.29.8；`sideEffects:false` 按图标树摇，40 个 ≈ 20-30KB）。替换纯文字符号：`▾▸`→ChevronDown/Right、`★☆`→Star、`✕`→X；NoteBlocks 的 `tree-caret` 同批。strokeWidth 1.5 呼应发丝线。另手绘 2 个产品自有 SVG：**大礼堂柱廊剪影**（空态/欢迎卡）、品牌标（「S」方块→柱廊线稿小徽）。

## 九、决策点（请逐条拍板）

- **D1 设计方向**：«文楷纸张·礼堂墨绿»（推荐）／备选 A「夜林冷调」（近黑绿+鲜叶，Linear 式）／备选 B「维持 indigo 只做排版升级」（最保守）。
