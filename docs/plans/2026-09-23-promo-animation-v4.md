## 1. 调研拿到的硬规则（两份 agent 检索，来源随附）

**脚本结构**（magichour / promohyper / medianug / smallfilms / ngram / hubspot 等）
1. 15–40s 短片按 Hook→痛点→转变→证据→CTA 五拍写，每拍 ≤5s，beat sheet 先于分镜。
2. 前 3 秒只放一个「状态改变」，不放 logo/口号/产品界面。
3. 70% 以上时长给「转变过程」的真实演示，文字只做框架。
4. Hook 用目标用户自己的话写具体场景；禁止用任何竞品也能贴上的类别形容词（"AI-powered" 之类）。
5. **只用在成片里能当场核对的产品事实做数字**（时间戳、页数、图片数），不用自编算术和个人库统计。
6. 全片只服务一个用户目标；功能巡展是 demo 视频第一死因；**每场景一个想法**。
7. **先展示「之后」（成品），再回溯「怎么来的」**。
8. **匹配剪辑**：讲课原帧 → 笔记里同一帧，让观众自己验证笔记真来自这节课。
9. UI 一律真实，禁止仿 UI 动画与假交互——假 UI 毁掉的正是「可信」这个卖点。
10. 每拍最多一行短字幕；个人使用数据（课程库数量、任务数）绝不上片。
11. Apple 式语法：克制排版 + 产品即主角，包装元素越少越显贵；结尾单一 CTA，禁止功能回顾蒙太奇。
12. 25s 内平均 1.5–3s 一切，静态镜头 ≤4s。

**动效工艺**（NN/g、Material 3、Spectrum、Atlassian、Carbon、BBC、Wikipedia、Emil Kowalski、W3C）
13. 幕内动效：reveal 200–500ms、micro 100–150ms、exit 150–250ms，**任何东西不超过 500ms**。
14. 三条曲线够用：**入场 ease-out、出场 ease-in、位移 ease-in-out**；控制点必须都在 `[0,1]²` 内（越界即"廉价弹跳"）。
15. 透明度/颜色永不做过冲缓动。
16. 交叉淡溶：两层同一时间窗、**同为 linear**，且出层保持 1 直到入层到 1（W3C 合成公式下总和恒等，不可能有凹陷）。
17. 尺度越大时长越长（大卡 400–500ms、文案 200–300ms）。
18. 1080p 字幕安全区 **1536×972**（左右各 192px）；一行 ≤37–42 字符、每格 ≤2 行；**低于画面高度 1.5%（≈16px）的字在手机上看不见**。
19. Ken Burns 每 3s ≤5%、一个方向、不把 UI 文字推出安全区。
20. 同一镜头只做一个运动想法；上一拍没落定下一拍不许开始。

## 2. 被否的 v3 踩了哪三条（对照规则自审）

1. **把不可核验的数字当卖点**：「75 分钟 → 14 分钟」听起来像把视频压缩短了，而产品做的是重组不是缩短（规则 5）；「1656 门课」是他的私人库统计，观众按"创始人私人数据"解读，反噬信任（规则 10）。两个数字同时掩盖了真正的差异点。
2. **demo 排成功能巡展**：五视图**切换栏本体**上了画面——那是机制不是结果（规则 6/9）；且所选案例没让「课堂原帧进入笔记」在 5 秒内可见，差异化不可感知。
3. **包装廉价**：屏幕堆字、自绘 UI（六阶段轨道、绿色 chips 都是仿 UI）、通用叙事（规则 9/11）。

## 3. 真正的卖点（v4 全片只讲这一条主线）

> **它不是"把视频变短"，而是把一节录播课重构成"可检索、可核验、可追问、可带走"的一册笔记。**

差异点按可演示性排序：① 每段笔记带时间锚与课堂原帧（**可核验**，别家没有）② 同一份笔记五种读法（一份 JSON 的五种投影，不是五份总结）③ 读到哪里问哪里（严格课时边界）④ 本地优先 + 自带密钥（无服务端、无遥测）⑤ 断了从断点继续（工程可靠）。

## 4. 演示案例换掉（这是"案例不好"的根因）

v3 用的是他私人库里的真实数据：一门 B站第三方数学课（含老师正脸与姓名）、两门「数据结构」、一条失败任务、一支 MV、1656 这个数。**这些都不是产品事实，且在 1080p/手机上都读不清。**

v4 改为**一次性 seed 的演示库**（真实 app + 真实 UI，只是内容换成干净可读的）：
- 课程「计算机网络」·「王老师」· 第 3 讲「TCP 的可靠传输」· 45 分钟（`duration_seconds=2700`）
- 笔记：6 条时间线（每条配 1 张课堂原帧，共 3 张不同帧）、8 个概念、10 节点导图、3 章、4 条关联线、2 道自测题——**标题全部短到手机上能读**
- 3 张合成"课堂幻灯片"位图（PIL 生成，白底+墨绿标题，与应用 print 样式同源），写入 `attachments/<lessonId>/keyframes/`
- 一条已写入的问答（供追问坞取景）
- 侧栏只留这一门课；任务历史只留 1 条完成态

**纪律**：成片里出现的数字只有这节课自己的（45 分钟、3 张图、6 个时间点），不出现任何库统计。

**演示案例**：seed 库（计算机网络 · 王老师 · 第 3 讲 · TCP 的可靠传输 · 45 分钟）+ 6 张 PIL 合成幻灯片 + 一份手写 note JSON（6 时间线 / 8 概念 / 10 节点导图 / 6 自测题 / 4 条关联）。**体检达到「良好」**（本地跑 noteHealth：warn 0；为此补了三件事：六条时间线各配一帧、概念定义拉到平均 60+ 字、摘引改成转写里的逐字子串、关联补关系词）。侧栏只剩这一门课、任务历史只剩 1 条完成态——**成片里的数字只有这节课自己的（45 分钟 / 6 个时间点 / 8 页讲义），没有任何库统计**。

**踩坑（本轮新增）**：
1. **`.head` 类被删导致标题飞出定位**——v4 重写 CSS 时漏了这个类，`left/top` 在 static 元素上不生效，「Flash Summary」渲染到了左上角；是海报帧目视抓出来的（抽帧小图里看不出来）。
2. **落点闪空帧复发**：v4 把内容起跑改回 `from`，又犯了 v3 修掉的错（六个落点全空一帧）；统一前移 0.3s 修复。**已连续两轮踩同一条，写进 PROGRESS 当铁律**。
3. **封面兜底帧取「≥60s 的第一帧」**（NoteViewer 的启发式：0s 标题页有黑边）——seed 关键帧时间戳要按这个来排，否则满幅开场那张和笔记里那张对不上。
4. **体检要能本地跑**：`src/shared/notes/health.ts` 不能直接 `node --experimental-strip-types`（相对导入无扩展名），拷四份到 .zcode/hc 再补 `.ts` 后缀即可（一次性）。
